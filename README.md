# EcoMetric 2.0

Ferramenta desktop para processar relatórios de venda de materiais recicláveis em PDF e gerar relatórios ambientais com indicadores de CO₂ evitado.

Projeto desenvolvido para a ACAMARTI (Associação dos Catadores de Materiais Recicláveis de Tibagi/PR).

---

## Requisitos

- Windows 10 ou superior
- Python 3.10 ou superior

---

## Instalação

```bash
git clone <repositorio>
cd "EcoMetric 2.0"
pip install -r requirements.txt
